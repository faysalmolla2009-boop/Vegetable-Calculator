# প্রোডাক্ট ক্যালকুলেটর

একটি সহজ ওয়েব ক্যালকুলেটর। প্রোডাক্টের মোট কেনা দাম ও ওজন দিলে প্রতি কেজি কেনা খরচ বের করে এবং কাঙ্ক্ষিত লাভ ধরে প্রতি কেজি বিক্রয়মূল্য দেখায়।

## ব্যবহার

1. `index.html` ফাইলটি ব্রাউজারে খুলুন (ডাবল-ক্লিক করুন)।
2. প্রোডাক্টের নাম, মোট দাম (টাকা), মোট ওজন (কেজি) লিখুন।
3. লাভের হার (ডিফল্ট ২০%) ঠিক করুন।
4. "হিসাব করুন" চাপুন।

ইন্টারনেট লাগে না। প্রোডাক্টের তালিকা ব্রাউজারের localStorage-এ সংরক্ষিত থাকে।

## হিসাবের নিয়ম

- প্রতি কেজি কেনা খরচ = মোট দাম ÷ মোট ওজন
- প্রতি কেজি বিক্রয়মূল্য = প্রতি কেজি কেনা খরচ × (১ + লাভের হার ÷ ১০০)
